# Standing rules for this repo

- **Commit straight to `main`.** Always commit and push directly to `main`. Never create a side branch or a pull request unless explicitly asked.
- **Single-file app.** This repo is a single-file app: `index.html`. It deploys automatically to GitHub Pages at https://maximumclosets.github.io/maximum-closets-hub.
- **Explain in plain language.** Jed is not a developer. Explain changes in plain language, not jargon.
- **Smallest edit possible.** Never reformat or reindent the whole file. Make the smallest edit that does the job.
